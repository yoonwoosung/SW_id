# Release Note / 변경 이력

FarmLink는 릴리스 단위 변경을 `docs/releases/`에 기록한다. (GitHub Releases를 병행해도 된다.)

## 원칙

- 커밋을 전부 나열하지 않는다. **병합된 PR**을 기준으로 아래 범주로 정리한다.

```text
Added        새 기능
Changed      기존 동작 변경
Fixed        버그 수정
Performance  성능 개선
Security     보안
Deprecated   곧 제거될 기능
Removed      제거된 기능
Documentation 문서
```

## 작성 방법

1. [template.md](template.md)를 복사한다.
2. `vX.Y.Z.md` 형식으로 저장한다. (예: `v0.1.0.md`)
3. 해당 릴리스에 포함된 PR 링크를 각 범주에 정리한다.
