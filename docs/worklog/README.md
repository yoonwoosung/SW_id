# 주간 개발 기록 (Worklog)

주간 기록은 **모든 커밋을 나열하는 문서가 아니다.** 이번 주에 있었던 중요한 일만 병합된 PR 중심으로 요약한다.

## 무엇을 기록하나

- 이번 주 목표
- 병합된 주요 PR
- 담당자별 완료 작업
- 가장 중요한 문제(주당 1~3개) — 원인·해결·검증
- 기술적 결정(ADR 링크)
- 다음 주 작업, 도움이 필요한 부분
- 포트폴리오 후보

## 운영 규칙

- 매일 작성하지 않는다. (주 1회)
- 커밋을 전부 복사하지 않는다.
- 병합된 PR을 중심으로 작성한다.
- 각 팀원은 본인이 수행한 PR 링크를 제공한다.
- 중요한 문제는 주당 최대 1~3개만 선정한다.
- 기술적 판단은 [ADR](../adr/README.md) 링크로 연결한다.
- 결과 수치가 없다면 임의로 만들지 않는다.
- 실패와 한계도 기록한다.
- 회사·학교·외부 기관의 비공개 정보는 기록하지 않는다.

## 작성 방법

1. [weekly-template.md](weekly-template.md)를 복사한다.
2. `archive/`에 `YYYY-Www.md` 형식으로 저장한다. (예: `2026-W31.md`)
