# 백엔드 요청: AI 추천 코스 모달 상세 정보 보강

> 작성일: 2026-09-04
> 담당: 프론트(준형) → 백엔드 요청
> 관련 화면: `오늘의 추천 코스` → 코스 카드 클릭 시 팝업 모달

---

## 배경

AI 추천 코스 모달에 사용자가 코스를 선택하기 전에 판단할 수 있는 정보를 충분히 보여줘야 함.
현재 API 응답(`/api/experiences/<id>/course`)에 빠진 필드가 있어 아래 항목을 표시하지 못하고 있음.

---

## 요청 1 — 코스 요약에 이동 시간 추가

### 목적
코스 요약 칩에 `총 N시간 · 이동 M분 · 자가용 추천` 형태로 이동 소요시간을 표시하기 위함.

### 현재 상태
`course.summary`에 `transport`, `barrier_free`, `estimated_cost`만 있음.

### 필요 필드
`GET /api/experiences/<id>/course` 응답의 `summary` 객체에 추가 요청:

```jsonc
"summary": {
  "transport": "자가용",
  "barrier_free": false,
  "estimated_cost": 38000,
  "travel_time_min": 22,   // 추가 요청 — 농장까지 예상 이동시간(분)
  "total_duration_min": 270 // 추가 요청 — 코스 전체 소요시간(분), 없으면 items로 계산 가능
}
```

> `total_duration_min`은 items의 첫/끝 time으로 프론트에서 계산 가능하므로 우선순위 낮음.
> `travel_time_min`은 프론트에서 계산 불가 → 필수.

---

## 요청 2 — 가격 항목별 상세 구성

### 목적
예상 비용을 총액이 아닌 항목별로 보여주기 위함.
예: `체험비 18,000원 + 식사 예상 12,000원 + 교통비 예상 8,000원`

### 현재 상태
`summary.estimated_cost`에 총액만 있음.

### 필요 필드
```jsonc
"summary": {
  "estimated_cost": 38000,
  "cost_breakdown": {         // 추가 요청
    "experience": 18000,      // 체험비 (필수)
    "meal": 12000,            // 식사 예상 (선택, 없으면 null)
    "transport": 8000         // 교통비 예상 (선택, 없으면 null)
  }
}
```

---

## 요청 3 — 편의 태그 (유아차 가능, 가족 추천 등)

### 목적
코스 모달 하단에 편의 태그를 보여주기 위함.
현재 `sm.barrier_free`(무장애), `sm.transport`(이동수단)로 일부만 파생 가능.

### 현재 상태
`유아차 가능`, `가족 추천` 등 편의 정보를 내려주는 필드 없음.

### 필요 필드
`summary`에 태그 배열 추가:
```jsonc
"summary": {
  "amenity_tags": ["주차 가능", "유아차 가능", "가족 추천", "반려동물 동반"]
  // 추가 요청 — 해당되는 태그만 포함, 없으면 빈 배열 []
}
```

> 프론트에서는 `amenity_tags`가 있으면 그대로 표시,
> 없으면 `transport`, `barrier_free`, `eco` 필드로 파생한 태그를 fallback으로 사용 중.

---

## 요청 4 — 추천 이유 상세 문장

### 목적
현재 `rec.reasons`는 짧은 라벨 배열(`["이전에 신청한 작물이에요"]`)이라
모달에서 자연스러운 문장으로 표시하기 어려움.

### 현재 상태
```jsonc
"reasons": ["이전에 신청한 작물이에요", "당일치기"]
```

### 필요 필드
```jsonc
"reason_text": "이전에 관심 보인 수확 체험과 비슷하고, 이동거리가 짧아 당일치기로 추천돼요."
// 추가 요청 — 자연어 한 문장, 없으면 프론트에서 reasons 배열 join으로 fallback
```

---

## 우선순위 요약

| 요청 | 우선순위 | 이유 |
|------|----------|------|
| 이동 시간 (`travel_time_min`) | 높음 | 코스 요약 핵심 정보, 프론트 계산 불가 |
| 추천 이유 문장 (`reason_text`) | 높음 | 현재 라벨 join이 어색함 |
| 편의 태그 (`amenity_tags`) | 중간 | 일부 fallback 있으나 유아차·가족 추천은 표현 불가 |
| 가격 상세 (`cost_breakdown`) | 낮음 | 총액은 표시 중, 상세는 부가 정보 |
