# 여행 조건 반영 — 최종 확인 체크리스트

갱신일: 2026-09-20 · 기준 커밋: `d1ffc2db` (`develop`)

## 0. 확인 전에 — 두 가지

- [ ] **서비스워커 캐시를 비운다**
      개발자도구 → Application → Service Workers → Unregister → 새로고침
      *조건을 바꿔도 결과가 그대로면 대부분 이것이다*
- [ ] **심사 직전에 주요 체험 3~4개를 미리 열어 둔다**
      관광공사 캐시(TTL 1시간)가 비어 있으면 첫 조회가 0.6초 → 1.5초가 된다.
      미리 열어 두면 캐시가 차서 계속 빠르다

---

## 1. 기준선 — 조건 없이

- [ ] 조건을 하나도 고르지 않고 AI 추천 → 코스가 **거리순 4곳**으로 나온다
- [ ] 09:00 체험 → 12:30 맛집 → 15:00 관광 → 17:00 카페

> 여기가 깨지면 나머지는 볼 필요가 없다.

## 2. 조건을 걸면 화면이 바로 반응하는가

- [ ] '이 조건으로 추천받기'를 누르면 **패널이 접힌다**
- [ ] 첫 추천 섹션으로 **스크롤이 이동한다**
- [ ] 접힌 토글에 **개수 배지**가 보인다 — "여행 조건 설정하기 ③"
- [ ] 조건을 다 지우면 배지가 사라진다
- [ ] 카드에 **"힐링 반영"** 같은 흰 배경 테두리 칩이 붙는다

## 3. 조건마다 코스가 실제로 달라지는가

같은 체험에서 조건만 바꿔 15:00 관광과 17:00 카페를 본다.

- [ ] **힐링** → 온천·리조트·유원지 계열
- [ ] **자연생태** → 공원·산 계열
- [ ] **수확** → 체험마을 (천안은 반경이 넓어져 '생거진천 화랑촌'이 나온다)
- [ ] **액티브** → 골프장·썰매장 등 레포츠
- [ ] **혼자·친구** → 관광이 박물관·카페로, **17:00 카페도 함께 바뀐다**
- [ ] **커플** → 공원·전망대 계열
- [ ] **3~5만원** → 더 싼 장소로 바뀐다
- [ ] **2박3일** → 더 먼 곳까지 후보에 들어온다

> 맛집(12:30)은 반려견을 고를 때만 바뀐다. 조건이 관광지 분류 위에
> 세워져 있고 음식점은 별도 분류라 구조적 한계다.

## 4. 슬롯 성격이 지켜지는가

- [ ] 17:00 카페 자리에 **진짜 카페**가 온다 (김밥집·순대집이 아니다)
- [ ] **반려견 동반**을 골랐을 때
      - 12:30에 식당, 17:00에 카페가 온다 (뒤바뀌지 않는다)
      - 애견동반 카페가 근처에 없으면 **"반려견 동반이 가능한 카페가 근처에
        없어 일반 카페로 구성했습니다"** 안내가 뜬다

## 5. 거짓 안내가 없는가

- [ ] **택시만** 골랐을 때 "조건에 맞는 장소가 근처에 없어…" 경고가 **뜨지 않는다**
- [ ] **반나절·당일치기·3만원 이하**만 골랐을 때도 경고가 뜨지 않는다
- [ ] 반대로, **충남 체험에 지역 '경기'**를 걸면 경고가 **뜬다** (맞는 장소가 실제로 없다)
- [ ] 반영 목록에 교통수단이 **"이동시간과 교통비를 이 기준으로 계산합니다"**로 보인다
      (예전엔 "찾지 못했습니다"로 떴다)
- [ ] 와이파이·무농약·유기농인증·노펫존은 **"체험 목록을 거릅니다"**로 보인다

## 6. 결과가 0건이 되지 않는가

- [ ] **대중교통만** 골라도 추천 결과가 나온다
- [ ] **택시만** 골라도 나온다
- [ ] **화장실만** / **수유실만** 골라도 나온다
- [ ] 반려견 동반가능 / 노펫존을 골라도 나온다

## 7. 소요시간

- [ ] **2~4시간** → 체험 하나만. "코스를 생성할 수 없습니다"가 **뜨지 않는다**
- [ ] **반나절** → 3곳 / **종일** → 4곳
- [ ] 시각(09:00·12:30·15:00·17:00)은 그대로다

## 8. 추천 섹션

- [ ] **비로그인**이면 섹션이 4개다 (내 주변·가볍게·단체·친환경)
- [ ] '내 또래'·'함께 가기'가 보이지 않는다
- [ ] 로그인해 나이·성별을 넣으면 두 섹션이 나타난다

## 9. 조건 반영 표시 전반

- [ ] 고른 조건이 **반영 또는 미반영 어느 쪽에든 반드시** 나온다
- [ ] 미반영 항목에는 **이유가 함께** 적혀 있다
- [ ] 화장실·수유실에는 **"예상"** 배지가 붙는다
- [ ] 조건을 **고른 순서**가 반영 비율에 반영된다 (먼저 고른 쪽이 크다)

## 알려진 한계 (고치지 않기로 한 것)

| 항목 | 상태 | 이유 |
|---|---|---|
| 맛집(12:30)이 조건으로 안 바뀜 | 유지 | 조건이 관광지 분류(A01~A03) 위에 있고 음식점은 A05. 음식 종류 조건 신설이 필요한데 마감상 제외 |
| 맛집 자리에 카페가 올 수 있음 | **미수정** | 7곳 중 1곳(천안)에서 발생. `_meals_only` 필터로 15분이면 가능 |
| 2명 | 미반영 | 제한 없이 모든 장소가 대상 — 기존 조건과 100% 겹쳐 제외(실측) |
| 무농약=수목원·생태원 | 넣지 않음 | 수목원(A01010700)이 자연생태(A0101) 하위라 부분집합 |
| 와이파이·노펫존=박물관 | 넣지 않음 | 문화시설은 후보 풀(관광지 12)에 없고, 넣어도 둘이 100% 겹침 |
| 힐링→조용한 카페 등 | 불가능 | 카카오·관광공사 어디에도 "조용함"·"분위기" 속성이 없다 |
| 광주 축약 표기 | 미지원 | "광주 북구"를 잡으면 "경기도 광주시"까지 끌려온다 |
| 반려동물 API | 403 | data.go.kr 활용신청 필요 — 카카오로 대체 동작 |
| 충남 올담 API | 점검 중 | 없어도 관광공사 결과로 코스가 만들어진다 |
