# 여행 조건 반영 — 직접 확인 체크리스트

갱신일: 2026-09-20 · 기준 커밋: `8422c159` (`develop`)

배포는 `develop` 푸시 시 자동입니다. 확인 전에 **서비스워커 캐시를 비우세요**
(개발자도구 → Application → Service Workers → Unregister → 새로고침).
조건을 바꿔도 결과가 그대로면 대부분 이 캐시입니다.

---

## 0. 먼저 — 아무것도 안 고른 상태

- [ ] 조건을 하나도 고르지 않고 AI 추천 → 코스가 **거리순**으로 나온다
- [ ] 코스 항목이 4개(체험 → 맛집 → 관광 → 카페)로 채워진다

> 기존 코스 생성이 깨지지 않았는지 보는 기준선입니다. 여기가 깨지면 나머지는
> 볼 필요가 없습니다.

## 1. 소요시간 (2026-09-20 추가)

- [ ] **2~4시간** → 코스에 **체험 하나만** 나온다
- [ ] 이때 "코스를 생성할 수 없습니다" 안내가 **뜨지 않는다**
- [ ] **반나절** → 체험 + 맛집 + 관광 **3개**
- [ ] **종일** → **4개** 전부
- [ ] 각 항목의 **시각(09:00·12:30·15:00·17:00)은 그대로**다
- [ ] 반영 목록에 "코스에 넣을 장소 수를 맞춥니다"가 보인다

## 2. 교통수단 (2026-09-20 수정)

- [ ] **대중교통만** 골라도 추천 결과가 **0건이 되지 않는다** ← 심사 전 필수
- [ ] **택시만** 골라도 0건이 되지 않는다
- [ ] 반영 목록에 "이동시간과 교통비를 이 기준으로 계산합니다"가 보인다
      (예전엔 "찾지 못했습니다"로 떴습니다)
- [ ] 자가용 → 대중교통으로 바꾸면 **예상 이동시간이 늘어난다**
- [ ] 자가용만 고르면 **주차 있는 체험만** 목록에 남는다

## 3. 편의시설

- [ ] **화장실만** 골라도 추천 결과가 0건이 되지 않는다 ← 2026-09-20 수정
- [ ] **수유실만** 골라도 0건이 되지 않는다
- [ ] 화장실·수유실 반영 표시에 **"예상"** 배지가 붙는다
- [ ] 와이파이·무농약·유기농인증은 "체험 목록을 거릅니다
      (코스 장소에는 반영되지 않습니다)"로 보인다

## 4. 일정 (탐색 반경)

- [ ] 당일 → 1박2일 → 2박3일로 갈수록 **더 먼 장소**가 후보에 들어온다
- [ ] 반영 목록에 "더 먼 곳까지 후보로 봅니다"가 보인다

## 5. 예산대

- [ ] 낮은 예산대를 고르면 **싼 장소**로 바뀐다
- [ ] 예산을 넘겨도 **슬롯이 비지 않고** 초과 안내가 뜬다

## 6. 액티비티 · 동반구성 · 반려견

- [ ] 승마·낚시를 고르면 코스에 **승마장·낚시터**가 들어온다(카카오)
- [ ] 액티비티를 고르면 **체험 목록**도 그 키워드로 걸러진다
- [ ] 동반구성을 여러 개 골라도 첫 조회가 지나치게 느려지지 않는다
- [ ] 반려견 동반가능/노펫존을 골라도 0건이 되지 않는다

## 7. 조건 반영 표시 전반

- [ ] 고른 조건이 **반영 또는 미반영 어느 쪽에든 반드시 나온다**
      (조용히 사라지는 것이 없어야 합니다)
- [ ] 미반영 항목에는 **이유가 함께** 적혀 있다
- [ ] 조건을 **고른 순서**가 반영 비율에 반영된다(먼저 고른 쪽이 크다)

## 8. 조건 순서·조합

- [ ] 조건 A → B 순서와 B → A 순서의 결과가 **다르다**
- [ ] 조건을 바꾸면 **코스가 실제로 바뀐다**(안 바뀌면 0번 캐시부터)
